## 📂 Progetti

### ✈️ TripFlow
App per la pianificazione di viaggi con architettura a microservizi, sviluppata in team come progetto universitario.
- **[Backend](LINK_TRIPFLOW_BACKEND)**: microservizi in Spring Boot. Ho progettato e sviluppato l'**itinerary-service**, il microservizio che gestisce gli itinerari di viaggio.
- **[App Android](LINK_TRIPFLOW_ANDROID)**: Kotlin, Jetpack Compose, Hilt. Ho sviluppato il modulo **feature-itinerary**, l'interfaccia collegata al mio microservizio.

### 📚 SmartLibrary
Gestionale per la gestione digitale dei testi di una libreria, con un'area dedicata all'amministratore e una ai clienti.
- **[Backend](LINK_SMARTLIBRARY_BACKEND)**: Spring Boot, Spring Security con autenticazione JWT, Spring Data JPA, database H2, generazione di PDF con OpenPDF, invio email con Spring Mail, test con JUnit 5 e Mockito.
- **[Frontend](https://github.com/mattia747/NOME_REPO_SMARTLIBRARY)**: interfaccia web per amministratori e clienti.
